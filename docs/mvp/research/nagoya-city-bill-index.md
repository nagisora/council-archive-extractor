# 名古屋市「議案の審議経過・結果」HTML 調査メモ

対象: 市公式サイトの議案一覧（市長提出／議員提出）。

## 入口ページ

- ハブ: `https://www.city.nagoya.jp/shikai/shingi/1030858/index.html`（ページ ID **1030858**）
  - 子リンク: **市長提出案件**（1030859）、**議員提出議案**（1030911）

## 会期ごとの一覧 URL

- 市長提出: `.../1030858/1030859/index.html` に、会期ごとの `<ul class="listlink">` リンクが並ぶ。  
  例: 令和7年2月定例会 → `https://www.city.nagoya.jp/shikai/shingi/1030858/1030859/1031911.html`（ページ ID **1031911**）
- 議員提出: `.../1030858/1030911/index.html` 配下も同様（例: 令和7年2月定例会 → **1031910**）

**安定キー**: 会期一覧 HTML の **ページ ID（ファイル名の数字）** を `session_page_id` として保持するのが実装しやすい。

## 一覧テーブル（市長提出・会期ページ）

`<table>` 1 本。`<caption>` に会期名。

| 列（thead） | 内容 |
|-------------|------|
| 議案番号 | 例: `第1号`（**`bill_number_raw`**） |
| 案件名 | 例: `令和7年度名古屋市一般会計予算`（**`title_raw`**） |
| 提出年月日 | 例: `2月19日`（年はキャプションの会期から補完） |
| 付議委員会 | HTML 改行を含む場合あり |
| 議決年月日 | 例: `3月21日` |
| 議決結果 | 例: `可決` / `否決`（**`decision_raw`**） |

**行単位の DOM**: `<tbody><tr><td>…</td>…</td></tr>`。`rowspan` は未確認だが、基本は **1 議案 = 1 行**。

## 議案 ID について

- サイト上に「システム上の一意 ID」は見当たらない。  
- MVP では **`{session_page_id}-{正規化した議案番号}`**（例: `1031911-1`）のように合成キーが現実的。

## 実装メモ（スクレイパ）

1. ハブから市長／議員のインデックスへ辿る  
2. 会期リンクを辿り `session_page_id` を取得  
3. `<table>` の各行から 6 列を抽出（案件名の前後空白を `trim`）  
4. 議案番号の全角数字・「第」「号」を正規化してキー化  

以上。
